## Overview

This repository contains the deliverables for the **Prioritized Risk Analysis** capstone assessment for the **ConnectSphere** platform. As an Independent Cybersecurity Governance Consultant, this assessment evaluates ConnectSphere's system design and processes for governance, risk, compliance, and security integrity.
